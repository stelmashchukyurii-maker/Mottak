SYNC MODEL:
- scanner/phone writes a full inventory-session snapshot after meaningful changes;
- localStorage remains fallback/cache;
- bootstrap reconciles local and server state;
- same-session records/zones are merged by the current bridge;
- PC/web polls latest snapshot approximately every 2.5 seconds;
- current server session can therefore be shared across phone/scanner/PC when network is available.
