Мета цієї розмови:
створити і фізично протестувати окрему Browser TEST-форму для щомісячної інвентаризації складу.

Основна логіка:
- inventory створює незалежну session/snapshot;
- під час обходу НЕ змінює WORK-stock;
- RFID scan → фактично що бачимо;
- Bunner stabel: default 10, можна змінити;
- Bunner + Hyller: ввести фактичну кількість полиць, не обмежувати лише 30/60;
- повторний RFID у тій самій session не рахується вдруге;
- неробоча/відсутня бірка → MANUELL → MAN-xxx → працівник відмічає товар фізично наліпкою/маркером;
- unknown RFID або server-status mismatch треба дозволити записати як physical evidence, але не змінювати WORK автоматично;
- після AVSLUTT порівняти SERVER FORVENTET ↔ FAKTISK TELT та сформувати AVVIK report;
- будь-яке майбутнє коригування WORK — лише окремо, audited, після людського підтвердження.
